# Changelog

## 0.2.0 — 2026-10-28

Instant ticket writes: an administrator can mark a write-scoped token so ticket replies, notes, ticket updates and sender blocks run without a per-request approval. All other writes still need approval. Optional signed ticket-change webhook (ticket id and event only) so a mirror such as Heaventree Control refreshes at once.

## 0.1.0 — 2026-10-06

Independent PHP addon, documented WHMCS local API catalog,10original BI tools, token/allowlist controls, atomic rate limit, payload-free audit, encrypted admin approvals, MCP prompts/resources and optional stdio client bridge. Read-first release candidate; no production deployment, provider mutation or full encrypted-vendor parity claim.
